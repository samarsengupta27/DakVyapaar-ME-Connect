# Dak Vyapaar — ME Connect (Firebase Spark)

Spark-only web application for Assam Circle.

Uses:
- Firebase Authentication (Email/Password)
- Cloud Firestore
- Firebase Hosting
- Browser-side Excel parsing with SheetJS

Does NOT require:
- Cloud Functions
- Cloud Storage
- Blaze billing plan

Important:
- Official Customer IDs are never generated by Dak Vyapaar.
- New onboarded customers use status ONBOARDING_PENDING and customerId = null.
- The official Customer ID is supplied by the Billing Application.

Deployment:
1. npm install
2. npm run build
3. firebase deploy --only hosting,firestore:rules,firestore:indexes

Before deployment, verify firestore.rules matches the rules already tested in the Firebase project.
